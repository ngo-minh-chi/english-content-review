# English Content Review Guidelines

## Purpose

This repository demonstrates a structured workflow for reviewing and proofreading English text. The objective is to improve language quality while preserving the author's original meaning.

---

# Review Process

Every review follows these steps:

1. Read the entire text carefully.
2. Identify grammar, spelling, punctuation, and formatting issues.
3. Correct errors without changing the intended meaning.
4. Improve readability where appropriate.
5. Perform a final quality check before completion.

---

# Evaluation Criteria

Each review is evaluated based on the following:

| Category | Description |
|----------|-------------|
| Grammar | Correct sentence structure and verb agreement |
| Spelling | Accurate spelling throughout the text |
| Punctuation | Proper punctuation usage |
| Capitalization | Correct capitalization of words and sentences |
| Meaning Preservation | Original intent remains unchanged |
| Readability | Text is natural and easy to understand |

---

# Quality Standards

A completed review should be:

- Accurate
- Consistent
- Easy to understand
- Grammatically correct
- Free from spelling mistakes
- Properly formatted

---

# Goal

The goal is to produce polished English content while maintaining consistency and attention to detail.
